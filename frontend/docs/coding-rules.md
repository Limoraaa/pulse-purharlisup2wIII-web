# Coding Rules

Gunakan:

TypeScript

Arrow Function

Functional Component

---

Selalu gunakan:

const

interface

type

---

Jangan gunakan:

any

class component

javascript

jsx

---

Gunakan import alias jika tersedia.

---

Component maksimal 250 baris.

Jika lebih,

pecah menjadi component kecil.

---

Pisahkan:

UI

Logic

Types

Dummy Data

---

Semua component harus reusable.

---

Gunakan naming:

PascalCase

untuk Component.

camelCase

untuk variable.

UPPER_CASE

untuk constant.

---

Semua file harus memiliki typing.

---

Gunakan React Hook.

---

Tidak boleh ada duplicate code.

Gunakan DRY Principle.
